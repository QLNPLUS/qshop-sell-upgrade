# Changelog

## 1.2.0

- The Magnet Upgrade now checks the Sell Upgrade in the same backpack before storing items it pulls in.
- Fixed the mod failing to load with Sophisticated Core 1.5.1 because of an invalid version range.
- Added Mixin support for Forge 1.20.1.

## 1.1.0

- Fixed Sell Upgrade and Advanced Sell Upgrade being rejected by Sophisticated Backpacks.
- Added optional Confluence Currency Combat price compatibility.

## 1.0.1

- Fixed the Sell Upgrade and Advanced Sell Upgrade textures.
- Removed both upgrades from the Sophisticated Backpacks upgrade tag.

## 1.0.0

- Initial release of QShop Sell Upgrade.
- Added Sell Upgrade and Advanced Sell Upgrade.
- Added whitelist and blacklist filtering with direct conversion to QShop currency.
- Added Forge 1.20.1, NeoForge 1.21.1, and NeoForge 26.1.2 branches.
